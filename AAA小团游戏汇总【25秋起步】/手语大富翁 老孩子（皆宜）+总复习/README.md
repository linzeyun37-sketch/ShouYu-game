## "大富翁" 手语版

**本资源包由杨守正&于沣林制作, 供手语分社小团使用**

同地址下的文件每份包含一个 Excel 表格 (`.xslx`) 或一个 Word 文档 (`.docx`), 以及一个 PDF 文件 (`.pdf`) ; 后者用于打印并发放 / 公示. 所含有的文件为

- 大富翁游戏规则

- 房产证 (地产证)

    打印, $1$ 份; 需要手动裁剪. 作为玩家购买或添置房屋的凭证, 上有金额标准.

- 词汇

    打印, $1$ 份以上; 需要手动裁剪, 如有裁纸机更佳. 此即传统 "大富翁" 游戏的货币. *请按照小团的实际教学进度, 适当地修改词汇内容*.

- 棋盘

    打印, $1$ 份. 如果有需要的话, 也可以修改棋盘上的内容; *请记得连带修改地产证的内容与数据*. 我们不建议更改机会格 / 监狱格等机制单元格.

**此处不包含棋子**, 您可以使用较重且体积较小的任意易辨识物品作为棋子, 例如某品牌柠檬茶小黄鸭, 或者可以吸附在黑板上的磁铁.
