# 指间趣游历史网页字体

当前网站使用 `../type-v2/` 中的资源圆体。本目录保留此前的字体、来源与许可证，当前页面不引用或打包这些字体。

- 原标题与正文：寒蝉全圆体 3.0，来自 [ChillRound](https://github.com/Warren2060/ChillRound)，子集字体名为 `SignPlay Round`。
- 历史字体：站酷快乐体，来自 [ZCOOL KuaiLe](https://github.com/googlefonts/zcool-kuaile)，子集字体名为 `SignPlay Play`。源记录与文件保留，当前页面不引用或打包此字体。

固定的上游提交、下载地址和原始字体 SHA-256 见 `sources.json`。两款字体均使用随目录提供的 SIL Open Font License 1.1。子集保留原版权，重新命名，完整许可证也写入字体 name 表，随单文件 HTML 内嵌发布。

此前使用的圆体 WOFF2 覆盖当时的网站静态文字和 ASCII，约 188 KiB。

当前字体的构建方式见 `../type-v2/README.md`；本目录的子集按历史版本保留。
